Privacy policy

Last updated: 18 October 2026

Emakulator Channel Tools ("the tools") are private desktop tools used only by their owner, for his own YouTube channels. They are not offered to the public.

YouTube API Services

The tools use YouTube API Services. By using them you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • Through the YouTube Data API: the owner's own channels, videos, playlists, captions and video details (titles, descriptions, languages, localizations, status, schedule).
  • Through the YouTube Analytics API (read-only): views, watch time, subscribers and similar statistics of the owner's own channels.

How the data is used

Only to set and verify the details of the owner's own videos and to show the owner reports about his own channels. No data is sold, shared with third parties, used for advertising, or combined with data from other users. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

OAuth tokens and reports are stored only on the owner's own computers and his own Google Drive. Nothing is stored on any server operated by the tools. The tools do not use cookies.

Retention and deletion

Channel statistics are kept only as the owner's own reports and can be deleted by deleting the report files. Stored API data is refreshed or deleted within 30 days as required by the YouTube API Services Developer Policies. Access can be revoked at any time at Google security settings (third-party access); revoking access stops all API use, and the stored tokens are then deleted.
